# Product

## Register

product

## Users

Administradores y owners de grupos de WhatsApp que usan OguriCap-Bot. Acceden al panel para gestionar el bot, subbots, grupos, pedidos de contenido, aportes, broadcasts, logs y analytics. Son usuarios técnicos pero no desarrolladores — esperan una interfaz clara, rápida y con personalidad propia.

## Product Purpose

Panel de administración en tiempo real para OguriCap-Bot, un bot de WhatsApp multi-device (Baileys). El panel permite controlar el ecosistema completo: estado del bot, subbots, grupos, contenido, usuarios, configuración SMTP/alertas, y analytics. La interfaz debe transmitir control, precisión y potencia — no debe sentirse genérica.

## Brand Personality

Técnico, oscuro, vivo. OguriCap-Bot tiene identidad de sistema que respira: partículas en movimiento, cursor glowing, acentos neon sobre negro profundo. La paleta base es verde WhatsApp (#25d366) como acento primario de vida/estado, con secondary teal (#2dd4bf) y accent purple/lavender. El tono visual es **Cyber/Terminal/Premium Dark** — Linear meets Raycast meets Bloomberg.

Three-word personality: **preciso, vivo, oscuro**.

## Tech Stack

- Next.js 14 App Router + React 18 + TypeScript
- Tailwind CSS 3.4 + Framer Motion 10
- Three.js (particle background)
- Socket.IO (real-time)
- Custom cursor, rough-notation annotations, animate.css keyframes
