OGURICAP BOT v2.1.0 — NUEVA GENERACIÓN
=======================================

Tag: OFICIALv2.1.0
Título: OguriCap Bot v2.1.0 — Instalador universal, nuevo panel y seguridad avanzada
Base comparada: OFICIALv1.0.0

Esta versión representa una renovación profunda de OguriCap Bot. Incluye un
nuevo sistema de instalación automática, panel modernizado, autenticación más
segura, protección de datos personales, nuevas herramientas administrativas y
mejoras generales de rendimiento, estabilidad y experiencia de usuario.


🌟 NOVEDADES PRINCIPALES
------------------------

• Nuevo administrador universal mediante ./oguricap.sh.
• Detección automática de Termux y distribuciones Linux.
• Instalación y configuración automática de PostgreSQL.
• Opción real para habilitar o deshabilitar el panel web.
• Panel completamente renovado y adaptable a dispositivos móviles.
• Nuevo sistema de autenticación con access token y refresh token.
• Cifrado de información personal mediante AES-256-GCM.
• Mejor administración de usuarios, perfiles, dispositivos y sesiones.
• Sistema ampliado de alertas, notificaciones y correos electrónicos.
• Mejoras importantes para sub-bots, grupos, aportes y proveedores.
• Dependencias actualizadas y suite de 165 pruebas aprobadas.


⚡ INSTALADOR UNIVERSAL
----------------------

El nuevo archivo oguricap.sh centraliza todas las operaciones:

• install: instala o repara dependencias.
• configure: configura owner, panel, secretos y PostgreSQL.
• start: inicia el bot y, si está habilitado, también el panel.
• update: actualiza sin borrar sesiones ni configuración.
• backup: crea una copia de seguridad de los datos privados.
• restore: valida y restaura un respaldo con confirmación.
• doctor: diagnostica el sistema y las dependencias.

El instalador reconoce:

• Termux en Android.
• Debian y Ubuntu mediante APT.
• Fedora mediante DNF.
• Arch Linux mediante Pacman.
• Alpine Linux mediante APK.

También instala Node.js 20+, npm, Git, FFmpeg, ImageMagick, PostgreSQL,
compiladores y las dependencias necesarias. En Termux actualiza los paquetes y
activa termux-wake-lock cuando el bot inicia.

Durante la instalación ahora se pregunta:

  ¿Habilitar el panel web? [S/n]

Si se responde S, el instalador descarga, compila e inicia el frontend. Si se
responde n, se omite el panel y se ejecuta únicamente el bot.

⚠️ ANTES DE ACTUALIZAR
----------------------

1. Crea un respaldo:

   ./oguricap.sh backup

2. Conserva estos archivos y directorios privados:

   • .env
   • Sessions/
   • backups/
   • storage/
   • .config/

3. Revisa las nuevas variables de .env.example.
4. Asegúrate de usar Node.js 20 o superior.
5. No publiques respaldos ni sesiones en GitHub.


📥 INSTALACIÓN NUEVA
--------------------

git clone https://github.com/melodiabl/OguriCap-Bot.git
cd OguriCap-Bot
chmod +x oguricap.sh
./oguricap.sh install
./oguricap.sh start


🔄 ACTUALIZACIÓN
----------------

cd OguriCap-Bot
./oguricap.sh update

Si el actualizador detecta cambios locales, se detendrá sin borrar nada.
Guarda esos cambios con Git o crea una copia antes de continuar.
